01AUTOMATION / DEMO HR SYSTEM

OrangeHRM automation

An end-to-end Selenium and pytest suite for employee records in the OrangeHRM demo PIM module.

I organized the suite with page objects for login, employee lists, personal details, job details, and shared UI elements. A session fixture handles the browser and login, while explicit waits and assertions check navigation, success messages, and results.

PythonSeleniumpytestPage objectsExplicit waits

View source on GitHub ↗

THE TESTED JOURNEY

  1. 01Log in to the demo dashboard
  2. 02Add an employee and capture the generated ID
  3. 03Search by ID and check the opened record
  4. 04Update personal and job details
  5. 05Delete with confirmation and verify the record is gone

The add flow also handles a duplicate employee ID by trying a new one.

02 / MY TOOLKIT

How I approach quality.

Tools help me repeat checks. Curiosity helps me decide which checks matter.

01

Follow the path

I start with a real task: what a person wants to do, which steps they take, and where confusion or failure could interrupt them.

02

Check the edges

I pay attention to validation, changing page state, filters, confirmation messages, and the smaller details around a happy path.

03

Make it repeatable

I use Python, Selenium, pytest, and explicit waits to turn suitable browser journeys into checks a team can run again.
